## 🏥 About the Project

This is a complete, production-ready, multi-page healthcare website for **DIMMA HOSPITAL & MATERNITY**, built to client-presentation standards with distinct medical and maternity branding, conversion-focused patient appointment pathways, mobile responsiveness, WCAG 2.1 AA accessibility, and local SEO schema.

---

## ✨ Key Features & Pages

1. **Home (`/`)**:
   - Compelling hero with tagline *"Compassionate Care. Trusted Healthcare. Healthier Families."*
   - Verified 4-pillar trust bar (Patient-Centered Care, Experienced Medical Team, Modern Healthcare Environment, Mother & Child Care).
   - Dedicated Maternity Wing spotlight section.
   - 12 Core Services catalog with interactive detail modals.
   - Philosophy & Values overview.
   - Health education articles preview.
   - Emergency contact & telephone direct banner.
2. **About Us (`/about`)**:
   - Hospital philosophy, patient dignity, family-centered care, safe maternity commitments, and Trans-Ekulu community healthcare presence.
   - Clean, verified editable management placeholders.
3. **Services (`/services`)**:
   - Interactive 12-department directory with category filters (Maternity, Clinical, Diagnostics) and instant real-time search.
   - Service detail modal with clinical protocols and direct booking action.
4. **Maternity (`/maternity`)**:
   - Flagship maternity showcase: Antenatal Care (ANC), Pregnancy & Foetal Monitoring, Safe Labor & Delivery, Postnatal Recovery (PNC), Newborn Care, and Family Support.
   - Trimester-by-trimester journey guide and Maternity Hospital Bag checklist.
5. **Medical Team (`/doctors`)**:
   - Departmental clinical leadership structure (Medical Director, Obstetricians, Physicians, Paediatric Specialist, Nursing & Midwifery, Pharmacy & Lab).
   - Structured for seamless future insertion of verified credentials and photos.
6. **Patient Information (`/patient-info`)**:
   - What to Bring (General, Antenatal, Inpatient/Delivery).
   - Step-by-step Patient Registration guide.
   - Visiting hours guidelines.
   - POS, Bank Transfer, and HMO billing information.
7. **Appointment System (`/appointment`)**:
   - Full interactive appointment booking form with real-time validation.
   - Notice: *"Appointment requests are subject to confirmation by the hospital."*
   - Booking confirmation summary with instant phone follow-up guidance.
8. **Contact & Emergency (`/contact`)**:
   - 1-tap direct calling (`08064689371`), interactive directions guide, verified operating hours placeholders, and online enquiry form.
9. **FAQ (`/faq`)**:
   - Accordion-based search and categorized questions for patient peace of mind.
10. **Health Articles / Blog (`/blog`)**:
    - Demonstration health articles (Preparing for First Antenatal Visit, Healthy Pregnancy, Newborn Care Basics, Emergency Warning Signs) with full reading view.

## 🛠️ Technology Stack

- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS with custom medical blue (`#004b9b`), maternity teal, and emergency red (`#dc2626`) palette.
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Typography**: Plus Jakarta Sans & Inter
- **SEO & Schema**: JSON-LD `MedicalOrganization` structured data, OpenGraph, Twitter Cards, localized keywords for Enugu and Trans-Ekulu.

---

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build production bundle
npm run build
```

## ⚙️ Content Management Configuration

All key hospital contact information, address, phone numbers, services, doctors, FAQs, and educational articles are centralized in:
`src/config/siteConfig.ts`

Any developer or hospital administrator can update contact numbers, operating hours, or doctor names in one single file.
